# NeuroCalm AI: SLM Data Dictionary

This document defines the strict, anonymized schema uploaded by the Flutter `SyncManager` to the Firebase Firestore `therapy_logs` collection. This data is structured specifically for fine-tuning future Small Language Models (SLMs).

## Collection: `users/{hashed_user_id}/therapy_logs`

| Field Name | Data Type | Requirement Ref | Description / Rules |
| :--- | :--- | :--- | :--- |
| `mood_score` | `int` | 6 | 1-10 scale. 1 = Severe Distress, 10 = Calm/Optimal. |
| `distortion_type` | `enum (String)` | 6 | Categorized CBT distortion (e.g., `catastrophizing`, `all_or_nothing`, `filtering`, `none`). |
| `session_duration` | `int` | 6 | Total session time in seconds. Used to weigh token efficiency. |
| `recovery_delta` | `int` | 6 | The difference in mood score from start of session to end of session. |
| `speech_rate` | `double` | E-002 | Words per minute (WPM) detected on-device. Extracted offline. |
| `encrypted_summary` | `String` | 4, 6 | AES-256 encrypted distilled summary. Max 150 tokens. Raw chat logs are NEVER stored here unless explicit consent is flagged. |
| `locale_region` | `String` | 2 | `IN`, `US`, `EU`, etc. Used to train culturally specific empathetic responses. |
| `timestamp` | `ISO-8601` | Core | Auto-generated by server upon sync. |

**Privacy Guardrails:**
* NO personally identifiable information (PII) is included in this payload.
* Biometric facial data (`E-003`) is strictly processed on-device and is explicitly excluded from this schema.
